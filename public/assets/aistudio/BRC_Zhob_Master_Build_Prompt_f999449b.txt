PUBLIC-FIRST AND AUTHENTICATION MECHANISM
1. Guest enters / and sees public Home. No login is required to browse public pages or access Apply Now.
2. Login is a separate optional action.
3. Verify credentials using password_verify against password_hash values. Rate-limit login attempts. Regenerate session ID after login.
4. Redirect by database role: Admin/Super Admin -> /admin/dashboard; Teacher -> /teacher/dashboard; Cadet -> /cadet/dashboard; Parent -> /parent/dashboard.
5. Recheck role, permission, user status and resource ownership server-side on every private request. Hiding links is not security.
6. No public account self-selection for privileged roles. Admin provisions teacher/cadet/parent accounts. Approved admission converts to a cadet once, without duplicate records. Parent accounts must be linked to verified guardian records.
7. Public header/footer remain available while signed in; users can navigate back to public pages.

SECURITY AND PRIVACY
- password_hash/password_verify; no plaintext or default shared credentials.
- Strict sessions, ID rotation, HttpOnly, SameSite, Secure cookies in HTTPS, inactivity expiry.
- CSRF on every state-changing POST and AJAX mutation.
- PDO prepared statements only; output escaping; strict validation; rate limits.
- Role + permission + ownership checks server-side on every private route.
- Safe file uploads: allowlisted extension/MIME/signature, max size, randomized names, no executable/script/HTML uploads, private storage outside public web root, authorized download controller.
- Deposit slip PDF/JPG max 2 MB verified server-side. Alumni image safe image formats only.
- Audit sensitive admin actions without logging passwords/tokens.
- Backups protected and restore-tested.
- Production HTTPS, least-privilege DB user, secrets outside web root, debug off, installer disabled after first Super Admin, directory listing off, security headers.
- Hide unconfigured Google OAuth, SMTP, SMS and gateway features; never fake them.
